# Alindal

A responsive, single-page landing site for Alindal, built with plain HTML, CSS, and JavaScript.

## Run locally

Requires Node.js. From this folder, run:

```sh
node server.js
```

Then open [http://localhost:3000](http://localhost:3000).

## Deploy with Vercel

Import this GitHub repository in Vercel. Select **Other** as the framework preset, leave the build command empty, and use `.` as the output directory. The site is served from `index.html` at the repository root.

The page uses Google Fonts and Unsplash-hosted images, so those assets need an internet connection in the browser.
